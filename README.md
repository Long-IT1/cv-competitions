# CV 竞赛项目

记录参加过的计算机视觉比赛：赛题分析、数据处理、模型方案、实验记录、最终成绩与复盘。

> 原则：**区分最终成绩、阶段成绩和个人实验**；不公开比赛规则禁止分享的代码或数据。

## 目录结构

```
cv-competitions/
├── README.md
├── competitions/
│   ├── _template/                 # 新增比赛时复制这个模板
│   │   └── README.md
│   └── <比赛名>/                  # 每场比赛一个目录
│       ├── README.md
│       ├── src/
│       ├── results/
│       └── assets/
└── .gitignore
```

## 每场比赛记录什么

| 项目 | 内容 |
|------|------|
| 比赛信息 | 名称、平台、官方链接、时间、队伍 |
| 赛题分析 | 任务类型、评价指标、数据规模 |
| 数据 | 来源、预处理、划分方式 |
| 方案 | 模型、训练策略、后处理 |
| 实验记录 | 不同方案的对比、调参记录 |
| 成绩 | 最终排名/分数（注明是最终成绩还是阶段成绩） |
| 个人工作 | 自己负责的部分 |
| 复盘 | 有效/无效的方法、踩坑、改进方向 |

## 如何新增一场比赛

```bash
cp -r competitions/_template competitions/<比赛名>
# 编辑 competitions/<比赛名>/README.md，把代码放进 src/，结果放进 results/
```
