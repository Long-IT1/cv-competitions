# FF 服装属性多标签分类

## 1. 项目简介

对 FF 服装数据集做 **12 个服装属性的多标签分类**：输入一张服装图片，同时预测 12 个属性（袖长、下装长度、袜子、帽子、眼镜、颈部配饰、手腕佩戴、戒指、腰部配饰、领口、是否开衫、是否遮脐）。

项目重点不是"跑通一个模型"，而是**用单一变量法做完整的实验迭代**：从 baseline 开始，逐个叠加数据增强、预训练权重、注意力、标签平滑、TTA、模型集成等方法，并记录每一步的实验结果。

## 2. 技术栈

- Python 3.x
- PyTorch + torchvision
- NumPy / Pandas
- scikit-learn
- Matplotlib / Seaborn

## 3. 数据说明

- 数据集：FF 服装属性数据集
- 标注：每行 = 图片文件名 + 12 个整数标签
- 训练标注：9188 行
- 测试标注：1149 行
- 12 个属性的类别数：`[6, 5, 4, 3, 5, 3, 3, 3, 5, 7, 3, 3]`

**数据划分**（官方切分）：

- 训练集：`train_ann_file.txt` 全部 **9188 张**
- 验证集：`val_ann_file.txt` 全部 **2296 张**
- 图片分散在两个目录（`train_images/` 10335 张 + `test_images/` 1149 张），按文件名匹配索引
- `test_ann_file.txt` 为 15 列标注，与本项目 12 属性方案不一致，**未作为最终评估集**

> 数据集与图片不随仓库提供，请按数据集原始来源获取。

## 4. 方法

实验按"单一变量"逐步叠加：

1. Baseline：ResNet-18
2. 数据增强（RandomCrop / HorizontalFlip）
3. 余弦退火学习率
4. ImageNet 预训练权重
5. CBAM 注意力
6. Label Smoothing
7. 热重启
8. CrossFusion
9. TTA（测试时增强）
10. Dropout 调参
11. **9 模型异构集成 + TTA**

## 5. 实验结果

**指标口径**：12 个属性各自准确率的平均值，在官方验证集（val_ann，2296 张）上评估。

| 结果 | 准确率 |
|------|------|
| 单模型最佳（EXP014 + TTA） | 93.67% |
| **9 模型异构集成 + TTA** | **94.37%** |

**实验迭代（官方验证集，12 属性平均）**：

| 实验 | 关键改动 | 验证准确率 |
|------|------|------|
| EXP003 | baseline + 数据增强 | 87.11% |
| EXP004 | + ImageNet 预训练权重 | 89.98% |
| EXP005 | + CBAM | 90.01% |
| EXP006 | + Label Smoothing | 90.10% |
| EXP007 | + 热重启 | 91.73% |
| EXP008 | + CrossFusion | 92.20% |
| EXP009 | + TTA | 93.32% |
| EXP014 | 多模型/多方法组合 | 93.42% |
| **集成** | **9 模型异构集成 + TTA** | **94.37%** |

**各属性准确率（集成 + TTA）**：

| 属性 | 1 | 2 | 3 | 4 | 5 | 6 |
|------|------|------|------|------|------|------|
| 准确率 | 94.82 | 95.43 | 96.65 | 99.39 | 100.00 | 91.81 |

| 属性 | 7 | 8 | 9 | 10 | 11 | 12 |
|------|------|------|------|------|------|------|
| 准确率 | 93.12 | 90.07 | 90.37 | 88.63 | 95.78 | 96.34 |

> 属性 10（领口）和属性 8/9（腰部/手腕配饰）是相对弱项，也是误差分析的重点。

## 7. 如何运行

```bash
pip install -r requirements.txt
```

1. 按数据集原始来源下载数据，放置到本地目录；
2. 修改 `src/dataset.py` 中的数据路径；
3. 运行单个实验：

```bash
python src/EXP001.py
```

4. 评估 / 集成：

```bash
python src/eval_official.py
python src/eval_tta.py
python src/eval_ensemble.py
```

> 模型权重（`.pt`）未上传，避免仓库体积过大；如需复现，请按 `src/` 中的实验脚本重新训练。

## 8. 项目总结

**有效的方法**：预训练权重、数据增强、CBAM、TTA、模型集成。

**局限**：

- 误差分析显示部分属性存在标注噪声/数据天花板；
- 集成带来提升，但推理成本相应增加；
- 未对每个属性单独做类别不平衡处理。

**改进方向**：

- 按属性分别调阈值/损失权重；
- 尝试更强的骨干（ConvNeXt / Swin）与蒸馏；
- 补充更严格的数据清洗与交叉验证。
